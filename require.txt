## 2. Cấu trúc Models (Ổ D - Folder Dự án)
Dự án lưu trữ model tại 2 vị trí (đều nằm trong folder dự án):
*   **Wav2Vec2:** `./wav2vec2-large-english-TIMIT-phoneme_v3` (Đã có sẵn)
*   **TinyLlama:** `./models/tinyllama` (Sẽ tự động tải vào đây khi chạy lần đầu)

## 3. Cách chạy ứng dụng

### Chạy Backend:
```powershell
python server.py
```

### Chạy Frontend:
```powershell
cd frontend
npm install
npm run dev
```

Truy cập: http://localhost:5173/
